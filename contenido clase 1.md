En esta unidad se está enseñando el diseño y la configuración de redes virtuales en AWS mediante el uso de una **Virtual Private Cloud (VPC)**. Los estudiantes aprenden a pasar de crear instancias EC2 en redes predeterminadas a diseñar su propia infraestructura de red, definiendo rangos de direcciones IP, segmentando recursos mediante subredes y controlando la conectividad y la seguridad de los servicios desplegados en la nube.

Se abordan los conceptos fundamentales de direccionamiento IPv4 y la notación **CIDR (Classless Inter-Domain Routing)**, incluyendo el cálculo de rangos de red, cantidad de direcciones IP disponibles y restricciones propias de AWS. Se enfatiza la importancia de planificar correctamente el espacio de direcciones antes de crear una VPC, ya que esta decisión afecta la escalabilidad, la conectividad con otras redes y futuras integraciones.

También se estudia la diferencia entre **subredes públicas y privadas**, comprendiendo cómo una subred pública puede comunicarse con internet mediante rutas adecuadas, mientras que una subred privada permanece aislada para alojar recursos sensibles como bases de datos o servidores internos. Además, se analizan las direcciones IP reservadas automáticamente por AWS dentro de cada subred y su impacto en la cantidad real de hosts disponibles.

La unidad profundiza en el funcionamiento del **Internet Gateway (IGW)** como mecanismo de conexión entre una VPC e internet. Los estudiantes comprenden que no basta con crear un IGW, sino que es necesario asociarlo a la VPC y configurar rutas específicas para permitir el tráfico hacia el exterior.

Otro tema central es el uso de las **Route Tables (tablas de rutas)**, las cuales determinan el camino que seguirán los paquetes de red según su destino. Se enseña a crear rutas locales para la comunicación interna de la VPC y rutas por defecto (0.0.0.0/0) para permitir el acceso a internet a través del Internet Gateway.

Finalmente, mediante actividades prácticas en la consola de AWS, los estudiantes crean una VPC, una subred pública, un Internet Gateway y una tabla de rutas, conectando toda la infraestructura para obtener una red funcional. Como cierre, se introduce el concepto de **Launch Templates**, destacando su utilidad para automatizar y estandarizar el despliegue de instancias EC2, preparando el camino para futuras temáticas de alta disponibilidad y escalabilidad.
