Escala de Notas (Escala Chilena - 60% Exigencia)

Fórmula de cálculo para la nota (de 1.0 a 7.0 con nota 4.0 al 60% de exigencia, es decir, con 60 puntos):

  • Si el puntaje es menor a 60: Nota = (Puntaje / 60) * 3 + 1
  • Si el puntaje es mayor o igual a 60: Nota = ((Puntaje - 60) / 40) * 3 + 4
