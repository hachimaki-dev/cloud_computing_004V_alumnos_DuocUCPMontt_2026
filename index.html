Guía de Bienvenida para el Profesor

¡Hola Colega! Bienvenido a tu asistente de clases rápido. Si no haces este ramo y te tocó como reemplazo de urgencia, no te preocupes. Hemos estructurado cada clase en 3 partes claras:

  • Teoría Simple (20-30 min): Te damos la analogía exacta del mundo real para explicar el concepto abstracto (ej. comparar VPC con un condominio privado).
  • Práctica Interactiva (40-60 min): No necesitamos consola de AWS. Las páginas de cada clase incluyen simuladores interactivos locales donde los estudiantes pueden ver qué pasa en tiempo real.
  • Metacognición (10-15 min): Preguntas y reflexiones guiadas al final para comprobar si entendieron los fundamentos y cerrar la clase con éxito.

💡 Consejo: Explora el contenido de la Clase 1 con el Modo Profesor activado antes de dictar para tener tus "chuletas" de teoría y preguntas listas.

Fundamentos de Cloud Computing

Aprende la arquitectura lógica de la nube a través de analogías directas, simuladores interactivos sin consola AWS y laboratorios locales de rápida ejecución.

Plan de Clases Disponibles

Clase 0 Disponible

Fundamentos de Redes y Binarios

La base de todo. Qué es una IP, cómo leen las computadoras en binario, cómo se calcula un octeto y de qué manera la máscara actúa como un candado para dividir la red del host.

90 Minutos Entrar a Clase
Clase 0B 🔬 Laboratorio

Tu Primera Red Local: Del Celular a la Nube

Construye una red real con el hotspot de tu celular, levanta un servidor web con Python y descubre por qué la máscara de subred define quiénes son tus "vecinos" en una red. El puente perfecto hacia VPC.

90 Minutos Entrar a Clase
Clase 1 Disponible

Redes Virtuales y VPC

Pasa de redes físicas a la nube. Entiende la segmentación en AWS usando rangos de IP, notación CIDR, subredes públicas y privadas, tablas de enrutamiento y el Internet Gateway (IGW) con nuestro simulador interactivo.

90 Minutos Entrar a Clase
Clase 2 Disponible

Seguridad y Resiliencia en la Nube

Defensa en profundidad usando Network ACLs y Security Groups. Aprende qué es el enrutamiento Stateful vs Stateless, el rol del NAT Gateway y cómo diseñar arquitecturas tolerantes a desastres (Multi-AZ).

90 Minutos Entrar a Clase
Clase 3 Disponible

EC2 y Cómputo (Servidores Virtuales)

Entiende la virtualización y el aprovisionamiento de máquinas. Usa la terminal web interactiva para "conectar" por SSH, y aprende cómo hacer público un servidor usando Ngrok o Glitch.

90 Minutos Entrar a Clase
Clase Especial Disponible

Introducción a Linux y Ubuntu Server

Comprende cómo piensa Linux, el puente mental desde Windows, la jerarquía de directorios y domina los comandos de terminal, edición con Nano y permisos en nuestro simulador local.

90 Minutos Entrar a Clase
Clase 4 Disponible

Almacenamiento de Objetos (S3)

Diferencias entre almacenamiento en bloque y objetos. Sube archivos a nuestro "Bucket Simulator" y descubre cómo los metadatos y permisos controlan la web moderna.

90 Minutos Entrar a Clase
Clase 5 Disponible

Identidad y Accesos (IAM)

Principio de mínimo privilegio. Usuarios, Roles y Políticas. Escribe tus primeras reglas JSON en el simulador IAM para permitir o denegar el acceso a recursos críticos.

90 Minutos Entrar a Clase

🔧 Talleres Prácticos con AWS

Laboratorios guiados paso a paso con acceso real a la consola de AWS.

Taller 1 🔧 Práctico AWS

Amazon EC2 + EFS desde Cero

Crea tu primera máquina virtual en la nube, conéctate por SSH con PuTTY, gestiona usuarios Linux, y monta un sistema de archivos compartido EFS con persistencia automática.

120 Minutos Iniciar Taller
Taller 2 🔧 Práctico AWS

Preparando un Servidor Linux en AWS

Aprovisiona una instancia EC2 con Ubuntu Server, gestiona identidades y permisos seguros a nivel de sistema de archivos, y configura un programador de tareas automáticas (cron) para producción.

60 Minutos Iniciar Taller
